Thirty one notebooks, worked end to end, because reaching for R every time somebody handed me a CSV had stopped being reasonable.

This is the Python side of the same skill. Indexing and filtering, groupby and multi indexing, joins, dates and times, text cleaning, type coercion, then matplotlib and seaborn for the plotting. I did every exercise before opening the solution, which is slower and the only way any of it sticks.

The part that changed how I work is groupby and apply. Most of the analysis questions I actually get asked are a split, an aggregate and a comparison, and once that shape is second nature the question stops being about code and starts being about whether you picked the right thing to split on.

I still write the exploratory pass in R out of habit. Anything that has to run more than once now gets written in pandas.
